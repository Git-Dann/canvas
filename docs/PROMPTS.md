# Prompts that work

Paste these into Claude Code in this repo. The skills fill in the rest, so one line is enough.

## New tools

- `Add a Voronoi tool: seeded cells, optional relaxation, outline or fill by palette.`
- `Add a spirals tool: Archimedean and log spirals, nested, with draw-on animation.`
- `Add a dot grid tool for web backgrounds: grid, hex and random layouts, size by noise.`
- `Add a glitch tool for uploaded images: slice offsets, channel split, scanlines.`
- `Add a QR-style pixel pattern tool that turns words into a seeded block grid.`
- `Add a wave text tool: words set along a sine path, repeated in rows.`
- `Add a blob avatar maker for 512px avatars, with initials in Inter.`
- `Add a starburst / sunray background tool with gradient rays.`
- `Add a word cloud / typographic poster tool from a block of text.`
- `Add a mesh gradient tool with seeded control points.`

## Changes

- `In <tool>, add a param for <thing>. Keep old files working.`
- `Make <tool>'s defaults more striking on the dark artboard.`
- `Add a palette called <name> with <colours>.`
- `Add a "<preset>" artboard at <w>x<h>.`

## Shipping

- `Run the verify gate and show me the screenshots.`
- `Publish Canvas into Foundry at /canvas next to /deck and open a PR there.`
